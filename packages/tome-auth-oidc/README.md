# tome-auth-oidc

OIDC authorization-code **authentication provider** for Tome (`implementationId: "tome-auth-oidc"`).

Registers with `AuthenticationHost` from `tome-interfaces/authentication`. Used when multi-user auth is configured to talk to an external IdP.

Feature spec: [`docs/features/multi-user.md`](../../docs/features/multi-user.md).
